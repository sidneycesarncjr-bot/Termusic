# Termusic
Projeto da turma de estrutura de dados da ufal - 2026


se trata de um player de musica direto pelo terminal. O projeto acadêmico e colaborativo, com divisão de responsabilidades entre frontend e backend.
A proposta é desenvolver um reprodutor capaz de organizar bibliotecas musicais, navegar entre músicas e controlar a reprodução de áudio


ferramentas utilizadas : 

Python: linguagem principal do projeto.

Textual: desenvolvimento da interface TUI(intaerface terminal.

Pillow: processamento de imagens e capas dos álbuns.

Mutagen: leitura de metadados de arquivos de áudio(artista, tempo de musica

Rich: renderização de elementos visuais no terminal(responsavel por colocar a foto da capa dos albuns de forma não pixelada.
